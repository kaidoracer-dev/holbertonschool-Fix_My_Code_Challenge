# Fix My Code Challenge

This project consists of fixing existing code in various languages without recoding everything from scratch.

## Files

- `0-fizzbuzz.py` - Fixed FizzBuzz condition order (FizzBuzz must be checked before Fizz)
- `1-print_square.js` - Fixed parseInt base from 16 to 10
- `2-sort.rb` - Fixed insert index from `i - 1` to `i`
- `3-user.py` - Fixed `_password` to `__password` and `.upper()` to `.lower()`
- `4-delete_dnodeint/delete_dnodeint_at_index.c` - Fixed missing node link update after deletion
